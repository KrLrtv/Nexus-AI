# NEXUS AI v2.0.3-alpha — Skill Studio: создание и тестирование новых модулей

Тестовый выпуск NEXUS 2.x на основе работающего голосового помощника M5StickC Plus2 и Termux. Обычная ветка NEXUS 1.x не затрагивается.

## Самообучение 3-го уровня

- После ответа «не могу» и команды «научись» NEXUS может самостоятельно сгенерировать новый модуль преобразования текста: описание, 1–7 операций и 2–6 тестов.
- Код и примеры проверяются через ограниченный локальный интерпретатор. Произвольный сгенерированный Python не исполняется.
- NEXUS сохраняет Python-файл проекта для просмотра, результаты тестов и SHA-256 в приватной папке Android.
- Если тесты не прошли, модуль не включается. Если прошли, NEXUS предложит открыть проверку в меню.
- В меню **Самообучение → Новые навыки → Проекты новых модулей / Проверить и включить модуль** можно посмотреть шаги и примеры, включить или отключить навык.
- Только после отдельного подтверждения «ВКЛЮЧИТЬ» текстовые навыки можно использовать голосом: «Нексус, навык 5: мой текст».
- Ранее освоенный навык SMS, отправка через Termux:API с подтверждением и все параметры M5 сохраняются.

## Честные ограничения

- Это генератор **ограниченных текстовых модулей**, не автоматическое исполнение произвольного Python или доступ к устройству.
- Задачи для Android, Telegram, USB, системы и перепрошивки M5 помечаются как требующие отдельного проверенного адаптера. NEXUS не выдаёт неподтверждённый успех.
- Сгенерированные тесты показывают согласованность со своими примерами, но не гарантируют корректность любых пользовательских данных.
- Запрос на создание текстового модуля отправляется Gemini только после команды «научись» или явного выбора пункта создания в меню.
- Новые исходники могут требовать проверки на твоём Android, GitHub CI проверяет только код и моделирование.

## Установка без терминальных команд

Открой NEXUS Control Center → **Обновить NEXUS**. При установленной 2.x будет использован отдельный канал экспериментальных обновлений. Для перехода с 1.x выбери **Версии → Установить NEXUS 2.0**.

После обновления открой **Самообучение → Новые навыки**. Для отмены обновления используй **Версии → Откатить последнее обновление**; ключи, Wi-Fi и прошивка M5 не перезаписываются автоматически.
