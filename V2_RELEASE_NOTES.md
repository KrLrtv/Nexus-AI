# NEXUS AI v2.0.4-alpha — Skill Forge Cycle

Экспериментальное обновление существующего GitHub-канала NEXUS 2.0.

- До трёх попыток разработки навыка: генерация, тесты, исправление по ошибкам.
- Первый корректный набор тестов фиксируется: модель не может подменить ожидаемый ответ ради прохождения проверки.
- Включение только владельцем через прежнюю Лабораторию модулей. Контроль SHA-256 и повторная проверка перед использованием.
- Повторное применение `навык <номер>: <данные>`; исправлена передача всей инструкции вместо аргумента после двоеточия.
- Одна предыдущая одобренная версия и голосовой откат `откати навык <номер>`; ограничение числа проектов.
- 35 новых регрессионных тестов плюс существующий набор тестов в CI.

**После обновления старые активные модули Forge нужно заново одобрить.** Их данные сохраняются, но прежние одобрения не содержат отпечатка исходника. SMS-адаптер не меняется.

Это не универсальное самопрограммирование: новые Android API и C++ остаются проектами для ревью; произвольный Python не запускается, стик не перепрошивается. После одобрения повтори запрос — задача не выполняется автоматически. Проверки Android/Gemini в unit-тестах подставные; физическое устройство отдельно не проверено.

Подробности: `docs/NEXUS_SKILL_CYCLE.md`.
