# NEXUS AI v2.0.3-alpha — Skill Forge

Экспериментальное самообучение: **NEXUS проектирует новый модуль, проверяет его и предлагает владельцу включить**. Разработано для M5StickC Plus2 + Android Termux, без изменения текущей прошивки.

## Что нового

- После отказа выполнить задачу фраза «научись» запускает генерацию черновика навыка через Gemini.
- Небольшие чистые Python-подобные функции проверяются на 2–5 примерах и исполняются только доверенным AST-интерпретатором, без eval/exec и импорта сгенерированного Python.
- Декларативные сценарии проходят проверку разрешённых read-only инструментов и сухую симуляцию без каких-либо действий с телефоном.
- Для задач, требующих нового Android API или кода M5StickC, создаётся Python/C++ черновик для просмотра; он НЕ выполняется, НЕ компилируется автоматически и НЕ прошивается.
- Все исходники, тесты и причины отказа доступны из меню. Включение готового модуля требует отдельного подтверждения владельца.
- Ранее освоенный модуль можно применить повторным голосовым запросом к исходной задаче. Неподдержанная функция не помечается освоенной.

## Только меню Termux

Открой **Самообучение → Новые навыки → Лаборатория новых модулей**.

В меню можно: создать новый модуль через Gemini, посмотреть проекты, изучить исходники и тесты, запустить повторную проверку, одобрить проверенный модуль, отклонить/отключить. Команд оболочки не нужно.

Для обновления уже установленной 2.x нажми в главном меню **«Обновить NEXUS»**. Выбор между 1.x и 2.x, откат и сохранение Wi-Fi остаются без изменений.

## Ограничения

- Готовые адаптеры Android остаются ограниченными реализованными функциями. Сгенерированный Python/C++ не становится автоматически системным драйвером или новым разрешением Android.
- Код M5StickC пока только проектируется как текст. Отдельно потребуются ревью, сборка PlatformIO, тестирование и явное подтверждение записи устройства.
- При обучении описание задачи отправляется Gemini; локальная память и контакты не передаются автоматически вместе с ним.
- Тесты автоматически проверяют ограниченный исполнитель и схему, но не гарантируют корректность нового модуля при любых входных данных.
- Проверки GitHub Actions не заменяют испытания на твоём Android и физическом M5StickC.
- Рабочая ветка 1.x не получает 2.x автоматически, прошивка M5 при обновлении не изменяется.
