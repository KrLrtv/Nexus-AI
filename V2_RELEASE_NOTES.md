# NEXUS AI v2.0.5-alpha — Auto Learn & Answer

После явной команды «Научись» или пункта меню «Научиться и сразу ответить»:
генерация → проверки/исправления → автоматическое включение → ответ на исходный запрос.
Повторно одобрять новый безопасный навык или повторять исходную задачу больше не нужно.

- Автовключение только для проверенных pure-функций и пяти существующих сценариев чтения.
- Отпечаток SHA-256, повторная проверка непосредственно перед включением и запуском.
- Уже включённый навык используется повторно без Gemini; выполненная цель снимается с ожидания.
- Неуспешные проекты и исходники новых системных адаптеров остаются черновиками.
- SMS по-прежнему требует подтверждения адресата и текста; прошивка, установка пакетов и произвольный Python не запускаются этим механизмом.
- Для обработки текста/числа отделяй данные двоеточием: «Переведи в верхний регистр: привет». Если данных нет, навык включится и попросит их, вместо обработки текста самой инструкции.
- Старые черновики автоматически не включаются. Отключение, ручное одобрение и откат сохраняются.

25 новых offline-тестов плюс существующий набор проверяют этот путь. Результаты CI нужно проверять для конкретного коммита. Живой Gemini, Android и M5 в unit-тестах заменены заглушками; испытаний на физическом устройстве не проводилось.

Это ограниченное освоение навыков, не универсальное самопрограммирование Android/M5.
