# NEXUS AI · M5StickC Plus2

**Текущий экспериментальный релиз — v0.1.5-alpha.**

В этом релизе исправлен запуск `apt-get` во время `tpio setup`: для установки пакетов Ubuntu используется стандартная эмуляция жёстких ссылок PRoot. Прежнее поведение могло давать `dpkg: Permission denied`. Голосовой помощник с M5StickC Plus2, локальным Android-мостом на Termux и облачным NEXUS Brain.

> ⚠️ Alpha: это снимок текущих исходников, а не гарантия полной совместимости с любым устройством. Перед прошивкой проверь Wi-Fi, токен устройства и параметры `platformio.ini`.

## Возможности

- Push-to-Talk: удержание кнопки A для записи речи.
- Локальное распознавание русского языка через sherpa-onnx в Ubuntu PRoot.
- Обработка текстовых запросов Gemini и ограниченный каталог инструментов Android-моста.
- Роботизированная озвучка eSpeak (если соответствующий модуль включён).
- Меню Termux через команду `nexus` и диагностика сервера.
- Исходники прошивки и возможность сборки через PlatformIO и `tpio`.

**Жесты, длительная автономная работа и скорость облачных ответов ещё требуют испытаний на устройстве.** Включённые функции зависят от того, что реально присутствует в этой версии исходников.

## Чистая установка (F-Droid Termux)

Установи **Termux** и **Termux:API** из одного источника — F-Droid. Затем в чистом Termux:

```bash
pkg update -y && pkg install -y curl && \
curl -fL --retry 3 -o "$HOME/nexus-install.sh" \
https://raw.githubusercontent.com/KrLrtv/Nexus-AI/v0.1.5-alpha/install.sh && \
bash "$HOME/nexus-install.sh"
```

Команда установит Python, Ubuntu PRoot, sherpa-onnx, eSpeak, инструменты сборки (`tpio`/`nrflash`) и локальную команду `nexus-stt`. Секреты пользователь вводит **только на своём телефоне**. Прошивка **не происходит автоматически**.

После успешной установки (при первом запуске можно настроить Wi-Fi прошивки и ввести ключи):

```bash
nexus
```

Сборка и прошивка по USB (после проверки параметров):

```bash
cd ~/nexus-firmware/firmware
tpio run -e m5stickc_plus2
```

Если сборка не проходит, не выполняй `tpio flash`: он может записать старый бинарник.

> Alpha-сборка: установка ещё требует проверки на реальном телефоне. Если возникнет ошибка, проверь `tail -n 80 ~/nexus-fdroid-install.log` и не отправляй личные ключи.

## Настройка и прошивка M5StickC Plus2

После установки запусти `nexus` и выбери **M5StickC Plus2**. В этом разделе доступны:

- ввод SSID и пароля Wi-Fi для M5StickC (пароль скрыт и хранится только в локальном `src/config_local.h`);
- просмотр статуса, сборка без прошивки, прошивка после явного подтверждения;
- «Собрать и прошить» — последовательная сборка и запись через `tpio`/`nrflash` при подключённом USB OTG.

**Wi-Fi больше не запрашивается во время установки.** Для изменения настроек M5 необходимо собрать и прошить новую версию. Ни пароли, ни токен не публикуются на GitHub.

## Обновление из Termux

Открой `nexus` → **Обновить NEXUS из GitHub** (один пункт главного меню) или выполни `nexus update`.
Обновление загружает только исходники и сохраняет ключи, локальную базу памяти и настройки Wi-Fi. Оно не перепрошивает M5 автоматически; после обновления можно отдельно собрать и прошить устройство.

Для возврата к предыдущей версии есть отдельный пункт главного меню **Откатить обновление NEXUS** или команда `nexus update --rollback`. Откат выполняется локально, без GitHub, после подтверждения и с сохранением текущих ключей и Wi-Fi.

**Без накопления резервных копий:** хранится только одна предыдущая версия исходников, старые копии автоматически удаляются после успешного обновления или отката. Кэш компиляции `.pio` в резервную копию не сохраняется. Просмотр: `nexus update --backups`. Удаление последней копии для освобождения места: `nexus update --clear-backups` (потребует подтверждения; после удаления откат невозможен).

Если установка прошлой alpha-версии прервалась на вводе Wi-Fi с `EOFError`, **не удаляй Ubuntu**: повторный запуск нового `install.sh` обнаружит исходники и попробует завершить настройку через `finish`.

## Структура

- `nexus-ai/` — Android-мост, NEXUS Brain, голосовые службы и Termux-меню.
- `nexus-firmware/firmware/` — исходники M5StickC Plus2.
- `install.sh` — загрузчик, закреплённый за релизным тегом.
- `scripts/termux-install.sh` — подготовка чистой среды.

В релиз входит новое терминальное меню `nexus` (старый интерфейс: `nexus --legacy`). Команда `nexus-stt status` проверяет локальное STT.

## Безопасность

API-ключи, SSID и пароли Wi-Fi, токены подключения, личная память и журналы **не должны храниться в репозитории**. Права Android выдаются самим Android по запросу. Не публикуй собранный `firmware.bin`, если он содержит реальные секреты.
