# NEXUS AI · M5StickC Plus2

Карманный голосовой помощник на **M5StickC Plus2** и Android (**Termux / F-Droid**).

**Статус: подготовка `v0.1.0-alpha`.** Репозиторий пока содержит инфраструктуру публикации. Исходники работающей прошивки и Android-моста ещё нужно перенести из текущего Termux. **Не считайте эту ветку готовым релизом NEXUS.**

## Архитектура

- **Device:** ESP32 / M5StickC Plus2, Push-to-Talk, экран, IMU, динамик.
- **Core:** локальный Android-мост (Python/Flask), хранение заметок, задач, событий.
- **Speech:** офлайн STT на sherpa-onnx и роботизированная озвучка eSpeak.
- **Brain:** Gemini и разрешённые инструменты Android.

## Структура готового релиза

```text
Nexus-AI/
├── install.sh                 # Входная точка чистой установки
├── scripts/termux-install.sh  # Подготовка Termux + окружения
├── nexus-ai/                  # Серверный код и меню `nexus` (предстоит загрузить)
│   ├── nexusctl.py
│   └── android_bridge/
└── nexus-firmware/firmware/   # PlatformIO и исходники ESP32 (предстоит загрузить)
    ├── platformio.ini
    └── src/main.cpp
```

## Чистая установка

После добавления и проверки **полных исходников** установка из Termux (F-Droid) будет запускаться так:

```bash
pkg install -y curl && curl -fsSLo ~/nexus-install.sh \
  https://raw.githubusercontent.com/KrLrtv/Nexus-AI/main/install.sh \
  && bash ~/nexus-install.sh
```

**Пока исходники отсутствуют, установщик должен остановиться с понятной ошибкой, а не выдавать ложное «установлено».** Прошивка по USB запускается отдельно и только по решению владельца. APK Termux:API нужно установить из того же источника, что Termux, и дать необходимые разрешения в Android.

## Безопасность

**Не публикуйте** пароли Wi-Fi, токены M5StickC, API-ключи, `.env`, базу памяти, журналы, кэш и скомпилированную личную прошивку. `.gitignore` не защищает секреты, уже записанные внутри исходников — перед загрузкой нужен аудит. Если секрет оказался в публичном коммите, его нужно перевыпустить.
