# NEXUS AI 2.0 — первый прототип самообучения

**Статус:** v2.0.0-alpha, экспериментальный предварительный релиз для существующей рабочей установки NEXUS 1.x.

## Архитектура

- **M5StickC Plus2:** микрофон, дисплей, кнопки и Wi-Fi; прошивка NEXUS 1.x остаётся совместимой.
- **Termux (Android):** сервер Flask, планировщик инструментов, база обучения SQLite, меню и управление локальными данными.
- **sherpa-onnx (Ubuntu PRoot):** локальное русское распознавание речи, без изменения модели.
- **Gemini/OpenRouter:** ответы на запросы; сохранённые сведения используются только при явном включении облачной персонализации.

Это **обучение на пользовательской обратной связи и извлечении памяти**, а не самостоятельное переобучение весов Gemini или модели распознавания. NEXUS не должен автономно переписывать собственные файлы, назначать новые разрешения Android или отправлять личную историю куда-либо сверх обычного запроса к облачной модели.

## Реализовано

1. Явное добавление фактов и предпочтений через голос или текст — «Запомни...», «Учти, что...».
2. Локальная оценка ответов — «Верно» / «Неверно».
3. Исправление последнего ответа — «Исправь ответ: ...»; точный повтор информационного вопроса может получить пользовательскую исправленную версию без облака.
4. Поиск воспоминаний по русским словам и частям слов — «Вспомни ...»; список — «Что ты обо мне помнишь».
5. Персонализация через Gemini/OpenRouter по явному согласию: до двух предпочтений и несколько релевантных фактов, всего не более около 1,2 КБ контекста.
6. Обособленная SQLite-база на Android: ~/.nexus_ai/learning_v2.sqlite3, лимиты 300 фактов и 200 записей обратной связи.
7. Просмотр, удаление по ID и полная очистка через меню и команду nexus learn.
8. Фильтр очевидных паролей, API-ключей и токенов; SQL-запросы параметризованы. Это не гарантия обнаружения любой конфиденциальной информации.

## Примеры

Голосовые команды:

    Нексус, запомни: я предпочитаю короткие ответы
    Нексус, что ты обо мне помнишь?
    Нексус, вспомни наушники
    Нексус, исправь ответ: правильное определение...
    Нексус, забудь запись 3

Команды Termux:

    nexus
    nexus learn
    nexus learn list
    nexus learn search "наушники"
    nexus learn sharing on
    nexus learn sharing off
    nexus learn forget 3
    nexus learn clear

Команда nexus learn sharing on включает отправку выбранных воспоминаний в Gemini/OpenRouter. По умолчанию выключено.

**Важно о приватности:** это переключатель только долговременной памяти. В NEXUS 1.x обычная история недавнего диалога уже передаётся Gemini при облачных запросах; выключение персонализации не отменяет существующий механизм истории.

## Установка превью на работающий NEXUS

**Только после появления GitHub-тега v2.0.0-alpha.** Уже работающую систему 1.x можно обновить явным выбором тестового тега:

    nexus update --tag v2.0.0-alpha

Обычная кнопка «Обновить NEXUS» продолжит использовать прежний канал releases/channel.json, закреплённый за проверенной 1.x. Для отката после теста:

    nexus update --rollback

Откат исходников не удаляет базу обучения. M5StickC не перепрошивается автоматически.

## Проверка и ограничения

- Автоматические тесты проверяют SQLite, исправления, локальный поиск, явные команды, защиту от типичных секретов, запрет передачи памяти в Gemini по умолчанию и персонализацию при включении.
- Проверки GitHub Actions не заменяют тест на физическом Android/M5.
- Локальные факты не являются проверенными внешними истинами; владелец может их исправлять и удалять.
- Самостоятельное обновление исходного кода, обучение весов модели, автоматическая публикация личных данных и незапрошенные действия через Android не включены.
- Дальнейшие этапы 2.x: оценка качества ответов, объединение дублирующихся знаний, сводки диалогов по согласию, миграция памяти 1.x, ограниченные автономные подсказки.
