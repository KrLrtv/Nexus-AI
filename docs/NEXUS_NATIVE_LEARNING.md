# Native learning preview (on top of v2.0.5-alpha)

Обычная задача теперь может запускать освоение недостающего способа без отдельного
«научись». Это доработка существующего сервера, не новая APK и не новая прошивка.

## Поведение

Сначала используются существующие функции. Для неизвестной операции планировщик
получает `learn_capability`. Исполнитель берёт исходный запрос пользователя,
а не подменённое моделью описание. После проверок он включает допустимый навык
и отвечает в том же запросе. Обычный разговор не запускает обучение.

Пример: `Сделай заглавными: привет`. После успешного освоения повторный запрос
`Сделай заглавными: другой текст` использует тот же способ без генерации.
Также поддерживается выделение данных завершающими кавычками:
`Сделай заглавными «привет»`. Совпадение операций нормализованное и точное,
не семантический поиск по произвольным перефразировкам.

Для функции без данных NEXUS спрашивает только недостающий ввод. Ответить можно
числом, текстом в кавычках или `данные: ...`, без номера навыка и без повторения
задачи. Ожидание действует 10 минут; посторонний разговор не считается вводом.

## Управление без терминальных команд

Голосом или текстом: `выключи автообучение`, `включи автообучение`,
`статус автообучения`, `останови обучение`.
В этом preview обучение включено по умолчанию. Выключение сохраняется локально;
ранее освоенные навыки остаются доступны. Для администрирования существует
`NEXUS_NATIVE_LEARNING=0`. Оно имеет приоритет над голосовым включением.
Обычный STOP сервера также отменяет текущее приобретение навыка.

## Границы

Не расширяется существующая политика `skill_autolearn`: только ограниченные
выражения и пять имеющихся адаптеров чтения. Новый системный адаптер остаётся
черновиком. Нет установки пакетов, исполнения произвольного Python, изменения
системных разрешений, автоматической прошивки или обхода подтверждения SMS.

Прохождение модельных тестов не доказывает универсальную правильность навыка.
Результат адаптера показывается как ответ инструмента, а не как подтверждённая
доставка или успешное внешнее действие. Для новых системных возможностей
по-прежнему нужны отдельные проверяемые адаптеры.

## Ограничения и состояние

Одно обучение одновременно, в том числе совместно со старым ручным механизмом.
До восьми новых обучений за скользящие 24 часа; каждое использует существующий
предел Forge — до трёх запросов генерации/исправления. Неудачная операция не
переобучается автоматически 10 минут. Квота относится к генерации навыков,
не ко всем обычным обращениям к модели.

После действий, уже выполненных в текущем запросе, обучение для всей задачи
заново не запускается. Недостаток доступа, сети, ключа или авторизации не
трактуется как необходимость написать новый модуль. После перезапуска старое
незавершённое обучение не повторяется автоматически.

Отмена кооперативная: HTTP-запрос к Gemini может завершиться, но после отмены
новый результат не активируется/не запускается. Если отмена обнаружена сразу
после активации, новый навык отключается. Уже начатое чтение нельзя гарантированно
прервать; оно может завершиться. Это не фоновый планировщик с доставкой позже.

Состояние хранится в `~/.nexus_ai/native_learning.sqlite3` с правами 0600.
В этой базе нет фактических входных данных, результатов или текста ошибок
провайдера. Описание операции хранится только для ожидания недостающего ввода.
Генератор навыка получает описание операции без явно отделённых данных.
**Первый обычный облачный запрос планировщика всё ещё может содержать весь текст
поручения. Это не режим полностью локальной обработки.** Повторное применение
найденного навыка обрабатывает данные локально. Приложение не добавляет ответы
native-механизма и их исходный ввод в будущую историю облачного диалога.

## Интеграция и проверка

`scripts/integrate_native_learning.py` сверяет Git blob SHA исходных `app.py`
и `planner.py`, проверяет точность всех замен и синтаксис до записи обоих файлов.
Повторный запуск идемпотентен; неизвестная или частично изменённая версия
отклоняется. Это миграция при сборке, а не самоперезапись во время работы.

Workflow отдельной feature-ветки выполняет миграцию, весь существующий набор
`nexus-ai/tests`, аудит публичных исходников и проверки синтаксиса; только после
успеха фиксирует изменения `app.py`/`planner.py` в этой ветке. `main`, релизные
теги, указатель preview и телефон пользователя автоматически не изменяются.

Новые offline-тесты проверяют оркестрацию с подменённым Forge; интеграционные
проверки используют реальные функции маршрутизации из исходников без запуска
Android. Реальный Gemini, Android, USB и M5 требуют испытаний на устройстве.
