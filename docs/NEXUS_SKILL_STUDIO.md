# NEXUS 2.2 · Skill Studio: «научись» → модуль → тесты → разрешение

Экспериментальная версия адаптивного NEXUS. Базовая версия NEXUS 1.x и работающая прошивка M5StickC Plus2 не меняются.

## Логика

1. Пользователь просит выполнить задачу.
2. Если NEXUS отвечает, что не умеет, он запоминает невыполненную задачу. После слова «Научись» он рассматривает возможность освоить её.
3. Уже реализованные доверенные адаптеры (например, SMS) работают отдельно и по своим правилам разрешений.
4. Для новых текстовых операций Gemini предлагает структурированный модуль с именем, кратким описанием, 1–7 операций и 2–6 тестами.
5. NEXUS проверяет схему и запускает тесты в ограниченном интерпретаторе действий. Произвольный Python, shell, вызовы Android и файловые операции не исполняются.
6. Генерируются файлы module.py (только для просмотра), tests.json и report.json. Python-файл не импортируется и не исполняется.
7. Меню «Самообучение → Новые навыки → Проекты новых модулей» показывает проекты. «Проверить / включить модуль» отображает шаги, результаты тестов и контрольную сумму.
8. Активация допускается только для успешного проекта после явного подтверждения «ВКЛЮЧИТЬ». Перед активацией повторно проверяются файл, SHA-256 и тесты.
9. Активный модуль применяется голосом: «Нексус, навык 5: мой текст» (5 — номер навыка). Можно отключить в том же меню.

Создание проекта не означает его автоматическую активацию; заявленные Gemini тесты доказывают только согласованность с приведёнными примерами, а не полную корректность алгоритма.

## Разрешённые операции

- Удаление пробелов по краям, изменение регистра (lower, upper, title, casefold)
- Сворачивание повторных пробелов, замена точной строки
- Префикс, суффикс, удаление заданных символов

Лимиты: вход до 600 символов, результат до 800, не более 7 шагов. Для этих операций не нужны новые разрешения Android.

## Запросы на действия с телефоном и M5

Если пользователь скажет «научись перепрошивать M5» или попросит новую системную операцию, NEXUS сохраняет проект со статусом needs_adapter и не притворяется, что может выполнить задачу. Требуется отдельный проверенный API/адаптер и разрешение владельца. Изменение прошивки M5 предполагает отдельный будущий конвейер: предложение патча → проверка диффа → изолированная сборка → тестирование → подтверждение USB-записи и откат.

Пример с сообщением «Напиши папе» по-прежнему выполняется отдельным обучаемым SMS-адаптером 2.0.2. Он требует явного подтверждения получателя и текста перед отправкой.

## Файлы и приватность

- База SQLite: ~/.nexus_ai/skill_studio/studio.sqlite3
- Артефакты: ~/.nexus_ai/skill_studio/<ID>/module.py, tests.json, report.json
- Права для директорий 0700; для файлов 0600
- Ни GitHub, ни стик M5 не являются хранилищем этих локальных проектов
- Только текст самой невыполненной **текстовой** задачи отправляется Gemini после явной команды «научись». Системные запросы/секреты блокируются до вызова API
- Локальные контакты, SMS-черновики, пароль Wi-Fi и токен NEXUS не включаются в генерацию

## Проверка и ограничения

CI проверяет модель данных, разрешённые операции, тестирование, неуспешные проекты, запрет автозапуска, подмену исходника, подтверждение владельца и голосовой вызов. Физический Android и M5StickC Plus2 требуют отдельного тестирования.

**Это первый генератор безопасных текстовых модулей, не универсальный программист с доступом ко всему устройству.** Следующий этап — проверенные адаптеры и отдельная безопасная сборка предложений изменений прошивки M5.
