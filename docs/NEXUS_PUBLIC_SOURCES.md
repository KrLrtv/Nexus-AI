# Самостоятельное освоение публичных источников

Это расширение существующего NEXUS 2.0.6: не отдельный погодный обработчик и не каталог заранее написанных сервисов.

## Реализованный путь

Обычный запрос -> планировщик выбирает learn_public_source -> определение параметров -> поиск документации через Gemini Google Search -> чтение до трёх документов -> генерация декларативного сценария -> проверка схемы и реальное чтение -> сохранение рабочего навыка -> ответ из полей полученных данных.

Вопросу не нужен повелительный глагол. Выполняется исходное поручение, не аргумент, переписанный моделью. После уже выполненных других действий повторный запуск всего поручения запрещён.

Если параметра нет, ассистент задаёт вопрос и хранит незавершённую задачу локально до 10 минут. Ответ обычным текстом проходит маршрутизацию как уточнение; посторонний разговор не должен становиться параметром. Город не определяется по IP, VPN, часовому поясу, этому чату или примеру в документации. Новые параметры должны быть фрагментами пользовательского ввода; это ограничивает выдумывание, но не доказывает правильную семантическую интерпретацию.

Совпадающий запрос с сохранённой привязкой повторяет чтение без генерации и поиска. Для перефразировки модель может выбрать существующий навык с новыми параметрами. Ответ источника НЕ кэшируется как актуальный факт. При изменении схемы или 404/410 допустимо одно ограниченное переосвоение. Сеть, 403, 429, неоднозначность и отсутствие результата не исправляются бесконечными попытками.

## Форматы и границы

Сценарий — данные, а не Python: до четырёх HTTPS GET, ссылки на параметры и результаты предыдущих шагов, обязательные проверки полей, до восьми выходных полей. Поддерживаются JSON, RSS/Atom, CSV и текст/HTML без JavaScript. Адрес должен присутствовать в действительно прочитанной документации. Нет списка погодных, валютных или иных предметных адаптеров.

Исполнитель запрещает credentials, произвольные заголовки, cookies, POST, локальные адреса и приватные сети. Проверенные DNS-адреса закрепляются за TLS-соединением с проверкой исходного имени сервера. Редиректы перепроверяются; для рабочих запросов смена домена запрещена. Ограничены размер ответа, таймауты, число DNS-потоков, документов и шагов. Это не песочница произвольного Python и не формальное доказательство безопасности любого внешнего сайта.

Поиск использует уже настроенный Gemini API key и выбранную модель. Она должна поддерживать Google Search; действуют квоты и условия тарифа провайдера. Поиск без groundingMetadata со ссылками не считается состоявшимся. Текст поискового ответа — только материал исследования; финальные значения выбираются из реально загруженных данных. Search suggestions сохраняются в ответе API и отображаются sandboxed iframe в локальной веб-панели; на M5 выводится текст результата и ссылки.

Дата `retrieved_at` — время загрузки, НЕ время обновления или гарантия актуальности сведений. Проверяются получение, структура и доступность полей. Правильность модели, надёжность сайта, единицы, выбор объекта и временная применимость не гарантируются такими проверками. Статус содержит `verification=fetch_and_schema_only`.

## Управление и данные

Общие команды «включи автообучение», «выключи автообучение», «останови обучение» и STOP распространяются на этот путь. Отключение навыка: «отключи интернет-навык N», где N — `source_skill_id` из результата. Отмена кооперативная: уже начатый HTTP-запрос может завершиться, последующие шаги проверяют отмену.

Сценарии, прочитанная документация, привязки запросов и явно переданные публичные параметры сохраняются в ~/.nexus_ai/sources.sqlite3 с правами 0600. У задачи-уточнения TTL 10 минут; у библиотеки лимит 30 записей. Локальная БД не зашифрована. История чата и контакты не добавляются в запрос разработки. Исходный запрос и пользовательское уточнение получает облачный маршрутизатор; выбранные параметры — публичный сервис. Это не полностью локальный режим.

Бюджет новых исследований общий с Native Learning: до восьми за скользящие 24 часа. Одна попытка исследования включает маршрутизацию, поиск и до двух вариантов сценария, не считая исходного вызова планировщика. Старые инструменты, системные разрешения, SMS-подтверждение и прошивка не изменены.

## Что ещё НЕ реализовано

Нет автономной установки Python-пакетов, управления произвольными Android-приложениями, авторизации в закрытых сервисах, чтения личных файлов, браузера с JavaScript и переписывания собственного ядра. Такие задачи не объявляются выполненными. Эта версия расширяет самообучение на публичные источники, а не завершает универсальное самопрограммирование.

## Проверка

237 локальных offline-тестов: 190 предыдущих и 47 новых. Реальный декларативный исполнитель и SQLite проверены с подменёнными сетью и моделью. Проверки GitHub Actions и отдельный публичный HTTPS smoke test выполняются для конкретного коммита. Живой Gemini, Android/Termux и M5 требуют проверки отдельно; нельзя считать тестовые сценарии доказательством работы любого нового API.
