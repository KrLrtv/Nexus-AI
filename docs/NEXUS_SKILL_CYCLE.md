# Skill Forge Cycle — v2.0.4-alpha

Развитие опубликованного Skill Forge v2.0.3, не отдельная установка и не замена NEXUS архивом.

## Что изменено

Команда «научись» и пункт создания модуля в существующем меню теперь выполняют ограниченный цикл разработки: генерация → проверка → передача ошибок модели → исправление. Всего допускается до трёх обращений к Gemini. При сетевой ошибке цикл прерывается без повторного расходования запросов.

Первый структурно корректный набор тестовых входов и ожидаемых результатов фиксируется до проверки исходника. Модель не может заменить ожидаемые результаты при исправлении программы. Это не доказывает, что исходные тесты верно понимают желание пользователя. API `propose(..., acceptance_tests=[...])` дополнительно принимает до пяти независимых приёмочных тестов; отдельного редактора этих тестов в меню пока нет. Эти примеры тоже отправляются Gemini.

Проект после успешных тестов остаётся выключенным. Включение — только через существующее меню владельца. SHA-256 связывает одобрение с задачей, исходником, сценарием и тестами. Проверки повторяются при одобрении и каждом применении. Это контроль целостности, а не защита от вредоносного процесса с теми же правами, который может переписать всю локальную базу.

## Управление

NEXUS → Самообучение · NEXUS 2.0 → Новые навыки → Лаборатория новых модулей.

Используй существующие пункты создания, просмотра, проверки, одобрения и отключения. Включение не отправляет SMS и не запускает задачу автоматически: после одобрения повтори исходный запрос или вызови навык с новыми данными.

Для текстового навыка запрос `Преобразуй текст: привет` передаёт функции только `привет`, а не всю инструкцию. Без двоеточия сохранено прежнее поведение для совместимости.

Повторный вызов: `навык 5: новый текст` или `модуль upper_text: новый текст`. Номер берётся из лаборатории, а не из примера. Для вычислений можно передавать JSON-число, например `навык 5: 12`. При совпадении имён у нескольких навыков требуется номер.

Если новая одобренная версия заменяет навык для той же задачи, хранится одна предыдущая одобренная версия. Фраза `откати навык 5` восстанавливает именно её. Это откат навыка, не исходников NEXUS и не прошивки. Отключение через меню не включает старую версию автоматически.

## Миграция и объём данных

База остаётся в `~/.nexus_ai/skill_forge.sqlite3`; добавляются столбцы без удаления старых проектов. У старых активных навыков нет зафиксированного отпечатка одобрения: они переводятся в `tested` и требуют повторного одобрения. SMS-адаптер и его база не затрагиваются.

Лимиты: до 50 активных навыков, одна предыдущая версия на активный навык и до 30 остальных недавних проектов. Повторное обучение не создаёт бесконечную цепочку резервных копий.

## Граница возможностей

Генерируемый Python остаётся данными для ограниченного интерпретатора выражений. Его нельзя импортировать или запустить как произвольную программу. Проверяются также неисполненные ветки выражения. Сценарии используют только существующие операции чтения Android-моста.

Новые Android API, произвольные системные команды и изменения C++ прошивки по-прежнему сохраняются как `proposal` для отдельной интеграции. Этот релиз НЕ реализует универсальную самостоятельную модификацию телефона или M5. SMS работает через ранее реализованный проверенный адаптер с отдельным подтверждением адресата и сообщения.

Для совместимости исходный модуль v2.0.3 сохранён без изменений как `skill_forge_runtime_v1.py`. Новый слой вызывает из него только валидатор, ограниченный интерпретатор и проверки примитивных значений; прежние функции хранения/генерации не используются.

## Проверки

Добавлены 35 регрессионных тестов: исправление после ошибки, неизменность тестов, приёмочные примеры, запрет автозапуска, контроль целостности, откат, миграция, конкурирующие одобрения, квоты, голосовой вызов, запрет скрытых опасных веток и отсутствие Android-действий при dry-run.

Локальные тесты используют заглушки облачного провайдера и Android. Workflow релиза дополнительно запускает весь существующий набор `nexus-ai/tests`. Успешные unit-тесты не заменяют проверку на реальном телефоне и M5StickC Plus2.
