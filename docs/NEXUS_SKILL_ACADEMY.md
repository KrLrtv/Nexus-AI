# NEXUS 2.0.2 — самообучение действиям («научись»)

## Зачем

В отличие от памяти NEXUS 2.0.1, Skill Academy сохраняет *неудавшиеся действия*, может освоить новый навык с помощью строго ограниченного Android-адаптера и впоследствии использовать его без повторной команды «научись».

Пример общения через M5StickC Plus2:

1. «Нексус, напиши папе».
2. NEXUS: «Сейчас не умею. Скажи „научись“».
3. «Научись».
4. NEXUS проверяет, доступны ли контакты и SMS через Termux:API; если Android не дал разрешение, предлагает открыть настройки телефона / повторить проверку в меню.
5. NEXUS локально находит контакт «Папа». Если вариантов несколько — просит выбрать номер; если совпадений нет — просит номер телефона.
6. «Я скоро буду дома».
7. NEXUS показывает выбранного адресата (последние четыре цифры номера) и ПОЛНЫЙ текст, спрашивает подтверждение.
8. «Подтверждаю отправку».
9. Только теперь NEXUS вызывает termux-sms-send и сохраняет навыковый адаптер после успешного ответа команды. Доставку SMS он не может подтвердить.

После первого успешного обучения для повторения достаточно «Напиши папе»: SMS-навык уже освоен, но сам текст и получатель *каждый раз* проверяются, передача требует отдельного подтверждения.

## Управление без команд

NEXUS → **Самообучение · NEXUS 2.0** → **Новые навыки · команда «научись»**.

Здесь находятся:
- Состояние доступных инструментов Android и SMS
- Подготовка SMS и контактов с добровольной установкой официального пакета Termux:API через pkg
- Список уже освоенных адаптеров
- Последняя невыполненная задача
- Повторное обучение
- Очистка незавершённых заявок

Android-приложение Termux:API устанавливается из F-Droid отдельно от терминального пакета; NEXUS не может обходить системные запросы разрешений. Для контактов требуется READ_CONTACTS, для отправки SMS — разрешения Android, в частности SEND_SMS и READ_PHONE_STATE.

## Расширение навыков

Для неизвестных задач NEXUS сохраняет отказ, а по слову «научись» может попросить Gemini составить **проверяемый сценарий** из уже реализованных только читающих (read-only) функций — например, собрать сведения о заряде телефона или локальных заметках. Созданный сценарий проходит проверку набора доступных действий и тестовый запуск; затем может быть использован для повторения этой же задачи. В таком сценарии запрещено создавать новый Python или вызывать произвольный shell.

Если ещё нет безопасного адаптера, NEXUS прямо говорит, что функция не освоена, и сохраняет заявку. Он не обманывает пользователя, будто получил неизвестные Android-разрешения.

**Изменение кода M5StickC Plus2** — отдельная следующая стадия. В v2.0.2 модель не может незаметно изменить исходники, собирать неизвестный код с повышенными правами, отправлять сообщения или прошивать микроконтроллер. Для изменения M5 потребуется отдельный цикл проверки: черновик патча → ревью диффа → синтаксис и сборка → тесты → разрешение пользователя на запись прошивки → сохранение отката.

## Безопасность и приватность

- База заявок/навыков: ~/.nexus_ai/skills_v2.sqlite3, локальные права доступа 0600.
- Временные состояния отправки истекают через 15 минут.
- Контакты читаются в локальном Termux-процессе и не включаются в запросы Gemini в SMS-сценарии.
- Номера телефонов не показываются целиком. Явно выбранный контакт обязателен для SMS.
- Нет автоматических SMS, автоответов или отправки «ради проверки»; требуются контакт, текст и подтверждение.
- Подтверждение — одноразовое, повторная отправка по той же реплике заблокирована.
- При неясном результате Termux:API NEXUS не повторяет отправку автоматически во избежание дублей.
- Модель не получает вызовы Termux:API в обход проверенного адаптера.
- Отправка SMS может тарифицироваться оператором связи; доставка не гарантируется.
- На некоторых версиях Android ограничения SMS и доступности Termux:API могут помешать навыку; эти условия нельзя обойти системным кодом без надлежащих разрешений.

## Тестирование

Автоматические тесты моделируют Termux:API, контакты и отправку: реальные сообщения во время CI не отправляются. Для работы на телефоне нужен ручной тест системных разрешений Android и пробное SMS *только с явным разрешением владельца*.

Рабочая прошивка M5StickC Plus2, локальное STT и обычные обновления NEXUS 1.x остаются без изменений.
