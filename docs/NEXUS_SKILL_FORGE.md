# NEXUS AI v2.0.3-alpha — Skill Forge

NEXUS теперь умеет **проектировать, проверять и предлагать новые модули** после команды «научись». Это попытка получить новую способность из существующих безопасных примитивов либо создать черновик исходников, который можно проверить.

## Алгоритм

1. Пользователь просит выполнить новую задачу.
2. Если NEXUS не умеет её выполнить, он сохраняет неудавшееся намерение локально.
3. На «научись» NEXUS обращается к Gemini с описанием задачи и запрашивает структурированный модуль.
4. Проверяет описание, код или сценарий и запускает ограниченные тесты.
5. Сообщает результат, вид проверок и номер черновика.
6. Владелец открывает «Самообучение → Новые навыки → Лаборатория модулей», изучает тесты и отдельно одобряет проверенный модуль.
7. После одобрения NEXUS может использовать освоенный навык при повторении исходного запроса.

Если даже черновик создать не удалось, задача не помечается выполненной.

## Три вида модулей

**Чистая функция (pure).** Небольшая функция вида def solve(value): return ..., поддерживаются только ограниченные строковые методы, вычисления, сравнения и срезы. Код НЕ запускается интерпретатором Python: доверенный компонент NEXUS читает AST и вычисляет только разрешённые выражения с ограничением длины, глубины и численных значений. Модель должна предложить 2–5 тестовых примеров, которые NEXUS независимо вычисляет. Примеры предложены самой моделью, поэтому эти тесты не доказывают корректность для всех случаев.

**Сценарий (recipe).** Один–четыре шага из уже реализованных функций чтения: заряд телефона, списки заметок/напоминаний, поиск в памяти. Доверенный модуль проверяет каждый шаг и делает dry-run с подставными результатами без Android-запросов и без отправки сообщений. Только после одобрения сценарий может выполнить доступные читающие функции.

**Черновик исходников (proposal).** Если задача требует нового Android API или изменений прошивки M5StickC Plus2, Gemini может подготовить текст Python или C++ для ревью. Этот код не выполняется и не устанавливается. Python проходит лишь проверку синтаксиса, C++ помечается как «не скомпилирован». Черновики нельзя включить через меню в обход отдельного ревью, сборки и тестирования интеграции.

## Управление в Termux — без команд

NEXUS / CONTROL CENTER → Самообучение · NEXUS 2.0 → Новые навыки → Лаборатория новых модулей

Пункты: создать модуль с Gemini, список черновиков, посмотреть код и результаты проверок, повторить тесты, одобрить проверенный модуль, отклонить/отключить модуль. Одобрение требует ввода слов «ОДОБРЯЮ» и номера модуля в самом меню, а не команды оболочки.

Обновления и откат исходников по-прежнему доступны через «Версии». M5StickC Plus2 автоматически не перепрошивается.

## Безопасность и приватность

- У NEXUS нет пути к eval, exec или импорту сгенерированного Python из нового модуля.
- Новые сценарии не могут запускать shell-команды, отправлять SMS, получать новые системные разрешения, обновлять прошивку или обращаться к USB.
- Отправка SMS остаётся отдельным проверенным навыком с подтверждением адресата и текста.
- Для проектирования модулей **описание последней невыполненной задачи отправляется Gemini**. Содержимое контактов и SMS для этого не требуется. Не диктуй токены, пароли и секреты как задание для Skill Forge.
- Локальная база Skill Forge: ~/.nexus_ai/skill_forge.sqlite3, с приватными правами файла. Старые неактивированные черновики удаляются автоматически, активированные навыки сохраняются.
- Успешные тесты проверяют только ограниченный сценарий. Они не гарантируют реальную доступность нового Android API или безопасность произвольного исходного кода.
- Для модификации M5 в следующем этапе нужен процесс: проект патча → ревью → сборка PlatformIO → тесты → разрешение владельца на запись → возможность отката.

## Пример

Пользователь: Нексус, создай новый способ обработки текста.

NEXUS: Такой функции пока нет.

Пользователь: Научись.

NEXUS: Создал черновик #3, проверки пройдены. Для включения открой Лабораторию модулей.

Пользователь одобряет навык через меню Termux, после чего NEXUS сможет применить его к тому же запросу. Это пока не свободное самостоятельное программирование и выполнение любых Android/M5 действий.
