# NEXUS AI v0.1.4-alpha

Промежуточная alpha-сборка для M5StickC Plus2 и Termux (F-Droid).

## Исправлено
- Внутренняя переменная VERSION установщика соответствует тегу выпуска. Ранее частично установленный NEXUS мог восстановиться из v0.1.2-alpha вместо актуального релиза.
- Теперь восстановление (`finish`) загружает именно v0.1.4-alpha и записывает корректную версию в локальный файл.

## Новое
- Раздел **M5StickC Plus2** в новом терминальном меню `nexus`: настройка SSID/пароля Wi-Fi, просмотр статуса, компиляция, запись через USB OTG и комбинированное действие.
- Запись прошивки возможна только при интерактивном подтверждении «ПРОШИТЬ»; отдельная сборка не пишет данные на M5.
- **Обновить NEXUS из GitHub** в главном меню и команда `nexus update`. Исходники обновляются через релизный ZIP с проверкой путей и Python-синтаксиса, старые версии резервируются. Локальная конфигурация Wi-Fi, ключи и пользовательские базы не заменяются.
- Исправлен `EOFError` на запросе Wi-Fi: установщик больше не читает ответы через Python heredoc.
- Установщик обнаруживает частично завершённую установку и поддерживает режим `finish` без повторного развёртывания Ubuntu.
- Добавлен канал обновлений `releases/channel.json` и автоматические тесты помощников.

## Установка
В свежем Termux F-Droid:
```bash
pkg install -y curl && curl -fL --retry 3 -o "$HOME/nexus-install.sh" https://raw.githubusercontent.com/KrLrtv/Nexus-AI/v0.1.3-alpha/install.sh && bash "$HOME/nexus-install.sh"
```

## Ограничения
- Тесты GitHub Actions подтверждают синтаксис, структуру и изолированные сценарии. Полная сборка прошивки/установка в Android и USB-прошивка требуют тестирования на конкретном телефоне.
- Для обновлений и зависимостей требуется доступ к GitHub/codeload; DNS и VPN могут влиять на загрузку.
- Обновление прошивки и обновление backend — разные операции; M5 не прошивается автоматически.
- Настройки Wi-Fi используются только при следующей сборке прошивки.
- Это alpha-релиз, не NEXUS 1.0 Stable.
