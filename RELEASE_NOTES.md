# NEXUS AI v0.1.5-alpha

Диагностическое обновление для меню Termux на Android.

## Исправлено
- При неуспешной операции меню M5StickC не заменяет полезную причину ошибки на общую `RuntimeError`.
- Если Wi-Fi ещё не настроен, меню подсказывает выбрать пункт 2 и ввести SSID/пароль сети 2,4 ГГц.
- Если сборка не прошла, появляется диагностическая подсказка `nexus m5 build`.
- Неуспешные операции подсвечиваются предупреждающим цветом.
- Добавлены автономные тесты сообщений об ошибке.

## Из предыдущего релиза
- Ввод Wi-Fi и сборка/прошивка M5 из меню Termux.
- Обновление и откат NEXUS из GitHub с сохранением одной предыдущей версии.

## Ограничения
Полная установка и физическая сборка/запись M5StickC Plus2 на Android ещё требуют тестирования. Это экспериментальная версия.
