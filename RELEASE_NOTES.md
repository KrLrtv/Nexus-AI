# NEXUS AI v0.1.6-alpha

Управление NEXUS только из меню Termux.

## Главное
- Все действия с версиями доступны через меню `nexus`: обычное обновление одним нажатием, выбор NEXUS 2.0 (эксперимент), возврат к ветке 1.x, откат и управление резервной копией.
- Экспериментальная 2.0 устанавливается **только после явного подтверждения**. Обычная кнопка обновления сохраняет текущую ветку версии.
- После обновления и отката меню автоматически перезапускается с новым исходным кодом — вводить команды не требуется.
- Опциональный автозапуск Control Center при открытии интерактивного Termux: переключатель в разделе «Версии»; по умолчанию выключен.
- Канал тестовых обновлений отделён от обычного: `releases/preview.json` указывает на релиз v2.0.0-alpha.

## Сохранено
- Wi-Fi и прошивка M5StickC Plus2 через меню, без автоматической USB-записи.
- Текущие API-ключи, база памяти и конфигурация Wi-Fi сохраняются при смене версии.
- Одна предыдущая резервная копия с локальным откатом без интернета.

## Ограничения
- Это alpha-сборка. Физический Android и сценарий переключения версий через меню требуют испытания на телефоне.
- Для загрузки обновлений требуется доступ к GitHub/codeload. После отката меню может выглядеть иначе, если старая версия ещё не содержала этот раздел.

Проверки исходников и логики меню проходят в GitHub Actions.
