# NEXUS AI v0.1.1-alpha

Второй экспериментальный исходный релиз NEXUS AI для M5StickC Plus2 и Termux из F-Droid.

## Исправлено
- Чистая установка: если Python ещё не установлен, загрузчик устанавливает его **до** проверки ZIP-архива (ошибка python: command not found).
- Архив исходников загружается через **codeload.github.com** вместо github.com/archive. Это может помочь при проблемах DNS с основным доменом GitHub.

## Входит в релиз
- Android-мост и обновлённое меню Termux NEXUS Control Center;
- Push-to-Talk, локальное русское STT на sherpa-onnx и озвучивание eSpeak;
- исходники прошивки M5StickC Plus2 и инструменты сборки;
- GitHub Actions с проверкой синтаксиса и исходников.

## Известные ограничения
- Полная установка на Android, работа STT и сборка прошивки требуют испытаний на реальном телефоне.
- Модель STT и Termux-PlatformIO скачиваются из сторонних проектов на GitHub: если сеть блокирует GitHub, установка может остановиться.
- Gemini может выдавать ошибки провайдера или тайм-ауты; жесты M5 требуют проверки.
- Ключи вводятся только локально; прошивка M5 автоматически не выполняется.

Это предварительный alpha-релиз, не стабильная NEXUS 1.0. Предыдущий v0.1.0-alpha остаётся неизменным.
