# История версий NEXUS AI

## v0.1.5-alpha — понятные ошибки сборки

- Меню M5StickC показывает исходную причину ошибки вместо общей надписи RuntimeError.
- При отсутствии Wi-Fi предлагает выбрать пункт 2 перед сборкой.
- Ошибки компиляции сопровождаются командой для диагностики `nexus m5 build`.
- Добавлены тесты корректного отображения ошибок.

## v0.1.4-alpha — исправление версии установщика

- Добавлен локальный откат через меню Termux и `nexus update --rollback`.
- После обновления или отката автоматически сохраняется только одна предыдущая версия, устаревшие копии удаляются.
- Добавлены команды просмотра и очистки резервных копий; кэш `.pio` исключён из копий.

- Внутренняя версия чистого установщика и режим восстановления теперь совпадают с тегом релиза.
- Добавлена автоматическая проверка согласованности версий, чтобы обновление не переходило случайно на прежнюю версию.

## v0.1.3-alpha — M5 Control Center и обновление из Termux

- Wi-Fi для M5StickC теперь настраивается через меню `nexus`, а не во время установки.
- Сборка и прошивка M5 доступны из отдельного меню (USB запись только с подтверждением).
- Обновление NEXUS из GitHub одной кнопкой с сохранением локальной конфигурации, резервным копированием и откатом при сбое копирования.
- Установщик умеет продолжать частично завершённую установку без повторного развёртывания Ubuntu.
- Добавлены автономные проверки безопасности ZIP-архивов, настройки Wi-Fi и обновления исходников.

## v0.1.2-alpha — исправление PRoot для tpio

- При настройке Ubuntu возвращена эмуляция жёстких ссылок PRoot (для dpkg и apt-get).
- Компиляция и параметры прошивки M5 не изменены.

## v0.1.1-alpha — исправление чистой установки

- Установщик теперь устанавливает Python до предварительной проверки исходников.
- Загрузка исходного ZIP переключена с github.com на codeload.github.com.
- Предыдущий v0.1.0-alpha остаётся без изменений.

## v0.1.0-alpha — первый исходный релиз

- Зафиксирована структура репозитория `KrLrtv/Nexus-AI`.
- Подготовлен установщик для чистого F-Droid Termux.
- Собраны серверный код и прошивка из текущих установленных исходников.
- Добавлена базовая проверка исходников при публикации.

Примечание: фактический состав патчей определяется содержимым опубликованного снимка.
